# Architecture Diagrams

The diagrams in this directory describe the logical trust zones, data flows, OSI boundaries, and planned hardening expansion.

The reference design contains:

- VLAN 10 Staff;
- VLAN 20 Guest;
- an 802.1Q trunk;
- a Layer 2 wireless bridge;
- an intentionally absent Layer 3 gateway in the base topology;
- a planned pfSense enforcement point and Elastic telemetry path.
