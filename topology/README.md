# Topology Files

The original course-provided GNS3 project is stored outside this repository. If redistribution is permitted, a sanitized copy or exported topology can be added here later.

Document the following after opening the project:

- device names and types;
- links and switch ports;
- VLAN assignments;
- VPCS IP and MAC information;
- access point bridge connections;
- intentional misconfiguration;
- any changes made during testing.
