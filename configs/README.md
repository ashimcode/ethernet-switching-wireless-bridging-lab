# Configuration Documentation

This directory contains sanitized configuration notes and control baselines.

Document, where applicable:

- access-port VLAN assignments;
- 802.1Q trunk VLAN allow-lists;
- native VLAN handling;
- unused-port and port-security settings;
- DHCP snooping and Dynamic ARP Inspection requirements;
- future firewall policy objects;
- future Sysmon and Elastic collection settings.

Do not commit production configurations, credentials, private keys, or unrestricted network exports.
